## 五、踩坑（六端可复用）

1. CF 503 优先看 body：`error code: 1102`（17B 纯文本）= Worker 资源超限，勿当应用层 503 排查。
2. python urllib 默认 UA 被 CF 防火墙 403 全拦——线上探测必须带浏览器头。
3. 测试环境 `@core/*`→src 与 barrel→dist 双类副本使 `instanceof` 失效——跨包错误判别用 name 哨兵兜底。
4. esbuild 动态 import 无 splitting 时内联为 `__esm` 惰性闭包：**bundle 体积不变但初始化延迟**——验证懒加载要看 `init_*()` 调用点位置，不看体积。
5. 本机 pnpm 缺失时：`corepack enable --install-directory <node目录>` 生成 shim；`CI=true` 防 pnpm 11 TTY 坑。
6. `route()` 内 `return promise` + 外层 `await route()` 的 try/catch 结构安全（1598 行 await 兜住 rejection）；async 化改造前先确认这个结构。
