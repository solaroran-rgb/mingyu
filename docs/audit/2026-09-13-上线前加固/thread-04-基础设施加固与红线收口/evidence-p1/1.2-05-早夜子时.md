## 红线要求
`dayDivide`（`forward` 晚子时归次日 / `current` 晚子时归当日）开关应真实驱动日柱与时柱，两种口径可复现。

## 实现位置 / 入口
- `packages/core/src/bazi/baziCalculator.ts`（§16 收敛；`dayDivide==='current' && solarTime.getHour()===23` 分支）
- 既有金标准：`tests/day-divide.test.ts` / `day-divide-blindspots.test.ts` / `ziwei-day-divide-wiring.test.ts`
  （金标准四柱来自 tyme4ts / lunar-javascript 交叉验证）。

## 验证方式
新增自动化测试：`tests/1.2-05-day-divide.test.ts`（3 用例，全部通过），固定 2024-03-15 23:30（晚子时 timeIndex=12）金标准：
1. `dayDivide:'forward'` → 年甲辰 / 月丁卯 / 日己卯 / 时甲子（次日）；
2. `dayDivide:'current'` → 年甲辰 / 月丁卯 / 日戊寅 / 时壬子（当日）；
3. 两种开关日柱确实不同（开关生效）。
