## 1. 现状审计结论（先摸清 schema 与消费方）

任务书里提到的 `public/data/cities.json`（约 25KB、34 国 448 城）**并未入库**，是 sky 线素材；
运行时真正消费的城市库在 `packages/core` 包内：

| 项 | 位置 |
|---|---|
| 源数据（入库） | `packages/core/data/globalCities.json` |
| 生成器（入库） | `packages/core/scripts/generate-global-cities.mjs`（源 JSON → 紧凑数组 .js） |
| 校验器（入库） | `packages/core/scripts/check-global-cities.mjs` |

| 测试 | `tests/1.1-04-location.test.ts`（4 用例） |

**GlobalCity schema（紧凑编码 11 列）**：
`id`(`geoname:<id>`) / `name`(本地名) / `nameAscii` / `country`(ISO α-2) / `language`(主语言) /
`admin1?` / `latitude` / `longitude`(WGS84) / `timeZoneId`(IANA) / `population` / `isCapital`。

> 说明：任务书假设的「中文名 zh 字段」在真实运行时 schema 里并不存在——`name` 是 GeoNames 本地名、
> `nameAscii` 是 ASCII 名。本线程**对齐真实消费方 schema**，不新增 zh 列（否则要动紧凑解码器与 .d.ts，
> 且无消费方需要中文名）。

**4 个既有用例的硬约束（红线，必须满足）**：
1. meta：`source` 含 `GeoNames`、`sourceUrl` 含 `geonames.org`、`timezoneSource` 含 `IANA`；
   `countryCount >= 34`、`cityCount >= 448`、`cityCount === getGlobalCities().length`。
2. 每条：lat/lng 有限且落在 WGS84 区间、`timeZoneId` 含 `/`、`id` 以 `geoname:` 开头。
3. `cities[0]` 的经纬度小数位 ≥4（实测首条即布宜诺斯艾利斯 -34.61315）。
4. 搜索/解析往返：`search('Tokyo')→Asia/Tokyo`、`resolve('Buenos Aires')` 纬度≈-34.61315、
   `findGlobalCityById` 回查；越界查询安全返回空。

## 6. 取舍说明

- **不做静态目录大文件前置**：产物是 `packages/core`（Node 算法包，服务端/排盘侧加载），
  不是浏览器首屏资源；生成器把 verbose JSON 压成紧凑数组 .js（11.33MB），且该 .js 已 gitignore、
  构建时由 `generate-global-cities.mjs` 从入库 JSON 再生成，仓库只入 33.37MB 的 JSON 源。
- **同名异城不去重**：10 万级地理库中同名异城（如多个 Springfield）是真实地理实体，
  去重会丢失它们；改为保留全部、搜索按 score+人口排序。校验脚本把「同国重名」由错误降为告警
  （本次告警 14,361 条，不阻断）。
- **language 字段放宽**：从 6 值枚举放宽为 ISO 639-1 主语言码字符串（新增 fr 等）。
  该字段无生产消费方（`getGlobalCitiesByLanguage` 无调用方），放宽向后兼容；
  校验仍强制 en/es/ja/ko/th/vi 六种目标语言各有覆盖、每国恰好 1 个 PPLC 首都。
- **未走 API 懒加载/分片**：11MB 紧凑数据在 Node 进程内一次性加载，O(n) 搜索在排盘服务侧可接受；
  若未来前端要内嵌搜索框，再按国家分片做懒加载（残留风险见 §7）。

## 7. 残留风险

1. **体积**：入库 JSON 33MB、运行时内存约 11MB；core 包 `files` 未把 data JSON 列入发布白名单，
   仅用于仓库内构建，npm 发包体积不受影响。
2. **搜索 O(n)**：`searchGlobalCities` 每次全表线性扫描，108k 行下单次约几十 ms；高 QPS 前端搜索场景
   需后续建索引或分片（本次不涉及）。
3. **同名歧义**：`resolve('Springfield')` 返回人口最大者；精确城市名建议带国家码/ID。
4. **非 en/es/ja/ko/th/fr 市场未覆盖**（de/pt/ar/ru 等）：按任务口径本期不收录；后续可再加国。
