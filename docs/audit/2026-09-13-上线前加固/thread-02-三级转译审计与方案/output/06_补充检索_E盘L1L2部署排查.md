## 五、对 T2 主审计结论的修订

1. **02/03 结论修正（等级不变、证据细化）**：2.1-01 的「L1 缺失」维持 ❌——资产线 68 条虽是真实古籍引文，但①粒度缺卷/页；②仅覆盖八字十神/干支/神煞的一部分原型；③无程序消费，不构成「已部署」。外围替身清单由 2 项扩为 **3 项**：1180 术语词典 + 盘面 prompt 生成器 + **资产线 318 条转译词库（含 68 条 L1/L2 级数据）**。
2. **05 执行方案 M2 重大利好**：决策 A 的 PrototypeEntry 与资产线 schema 高度同构（archetypeKey/evidenceQuote/professionalDef/translations 一一对应），**M2 的数据生产不必从零开始**——68 条八字 L1/L2 级数据可直接迁移校验，schema 契约（含 licenseTier 版权分层、P6 禁用词）可整体继承；M2 工作量重心从「设计+造数」转为「对齐 schema + 补齐 15 体系 L1 + 建消费程序（运行期查表）」。M2 14 人日估不变偏乐观余量增大。
3. **给主控的建议**：上线前若做 M1（运行时约束），应同步把资产线词库的 `professionalDef`/`translations` 作为 LLM system prompt 的术语参考注入（查表注入，仍零生成），即可以最小成本先吃到 318 条存量数据的红利。
