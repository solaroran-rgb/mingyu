## 一、什么是「三级转译」

**转译链 = L1（古籍锚定）→ L2（现代注疏）→ L3（通用白话）→ L4/L5（树状投射矩阵/场景文案）**，468 红线体系 2.1 节定义 24 项检查点；塔罗红线 1.4-05 要求塔罗牌义走与八字/占星相同的同一链路。

- **白皮书口径**（3.6 板块清单）：「内容词库与内容 i18n｜L0–L7 转译、800 条 MVP、术语词典、内容级多语言｜归属专家 C」。⚠️ 实测白皮书正文（压缩单行版）仅板块清单提到 L0–L7 一次，**L0-L7 逐级详细定义不在代码部分白皮书中**，权威定义在 468 红线 2.1 节。
- **CTO 计划口径**：Phase3 词库 MVP = 800 条（八字 480 + 紫微 330），放弃 5000 全量；白皮书 2.2 拍板「词库范围 MVP 800 条」。
- **技术契约口径**（白皮书 2.3）：证据型输出四件套（calculationSteps/evidence/limitation/counterEvidence）；`archetype_key` 命名 `{system}-{category}-{term}-{variant}`（如 `bazi-shishen-qisha-001`），词库条目与引擎输出共用此键对接。

## 二、24 项红线逐项「原计划应部署内容 + 验收标准」（提炼自红线原文）

| ID | 检查项 | 原计划应部署内容 | 验收标准（可判真假） |
|---|---|---|---|
| 2.1-01 | L1 古籍锚定 | 每个命理原型入库必带 `《书名》卷X·第X页·原文引用`；无出处标 `source: NONE` 禁止进 L2+；古籍限《四库全书》子部术数类+公认经典 | 抽查任一原型可溯源到卷/页/原文；出处格式正则可校验 |
| 2.1-02 | L2 现代注疏 | 每条 L1 配 ≥1 位公认学者注疏（≥3 部出版物），格式 `注疏者·著作·出版社·年份·页码·内容` | 注疏者资质可查；注疏通过 IP 相似度检测 |
| 2.1-03 | L3 通用白话 | L2 → 中性白话：禁宿命论绝对化词；概率性表达；难度 ≤ 初二水平；≤200 字；禁医疗/法律/金融建议 | 敏感词表 0 命中；字数达标；语义不失真不坍缩 |
| 2.1-04 | L4/L5 树状投射矩阵 | L3 → L4 ≥4 领域（事业/财运/感情/健康…）→ L5 每 L4 下 ≥3 人群标签，文案结合人群特征 | 高频原型（≥800 个）100% 覆盖 L4-L5 |
| 2.1-05 | 场景文案防越界 | 越界判定四规则：主体不可扩展/程度不可升级/领域不可跨界/时间不可延长；审计 Agent 语义对比 L5 vs L1，标记 `boundary_violation` | 越界文案检出即下线；判定标准可执行 |
| 2.1-06 | 转译越界熔断器 | L3→L5 链设「语义距离熔断器」：L5 出现 L2 未提及的具体事件/疾病/金额/时间即熔断 `fused: true` 禁止上线返回重写；Temperature=0；词库版本冻结；注入防护 | 熔断日志入审计；越界样本必被拦截 |
| 2.1-07 | 用户画像篡改法理防御 | 画像只影响表达视角/举例/建议方向，**绝不改变吉凶定论**；画像只进路由模块不进 AI 生成模块 | 吉/凶/平定性不随画像变 |
| 2.1-08 | 多语言合规脱敏 | 各语言禁绝对化表述；脱敏规则**硬编码**（非 AI 动态判断）；目标市场敏感词表由当地法务提供 | 中/英/日/韩等敏感词硬编码替换，译文吉凶方向不变 |
| 2.1-09 | 词库版本化控制 | 每份报告附三元组 `engine_version + dict_version + model_version`；历史报告按生成时版本渲染恒定不变 | 报告 JSON 元数据含三版本号且不可篡改 |
| 2.1-10 | 人工审核签字 | L1-L5 每条入库双重签字（命理顾问 + 法务/UX），记录存档 ≥5 年，CI/CD 校验签字字段非空 | 抽查任一条有签字记录 |
| 2.1-11 | 树状结构完整性 | L5 叶子可 100% 上溯至 L1；随机抽 100 个 L5 追溯 L5→L4→L3→L2→L1 无断链 | 断链检测纳入 CI/CD A 类 |
| 2.1-12 | 文案非重复性校验 | L5 两两余弦相似度 <0.7（TF-IDF/Sentence-BERT），≥0.7 标记疑似重复人工确认 | 相似度检测脚本可运行（B 类每周） |
| 2.1-13 | 覆盖率验证 | 高频原型 ≥800 个 100% 覆盖 L4-L5；低频 ≥200 个 100% 覆盖 L3；验证脚本每月自动运行 | 覆盖率看板存在，<100% 禁止上线新功能 |
| 2.1-14 | 规则冲突裁决树 | 矛盾原型走裁决树：格局>十神>神煞>纳音；同级取力量强者；裁决 JSON `{conflict, resolution, confidence}`；仅主基调匹配词库 | 同盘矛盾原型有唯一主基调输出且过程透明 |
| 2.1-15 | 术语映射表 | 专业术语→现代心理学/生活化映射（七杀→执行力/压力/竞争…），双审 + 版本化 | 映射表存在、版本化、有审核记录 |
| 2.1-16 | 兜底安全回复 | 审计超时/失败/异常返回预设通用安全回复，禁技术错误信息/空文案/技术堆栈 | 异常路径 0 技术术语泄漏 |
| 2.1-17 | 心理安全文案审核 | 敏感原型（孤寡/刑克/灾厄…）文案由持证心理咨询师审核：不引发焦虑、成长导向、无宿命论 | 审核记录签字存档 |
| 2.1-18 | 禁止医疗诊断 | L3-L5 禁具体疾病名/手术/药物/死亡预测；仅泛化表达 | 违禁词扫描 0 命中 |
| 2.1-19 | 禁止法律/金融建议 | 禁具体法律行动/金融操作/人生决策指令；仅趋势描述 | 违禁词扫描 0 命中 |
| 2.1-20 | 多语言一致性校验 | 同一原型 ≥8 语言版本吉凶方向一致（双语顾问逐条校验 `direction_match`） | 不一致项禁止上线 |
| 2.1-21 | 文化敏感性审核 | 禁种族/性别歧视、宗教冒犯、政治敏感；本地化专家按市场审核（中东/东南亚/欧美/日韩各一套清单） | 审核清单 + 记录存在 |
| 2.1-22 | 文案可读性分级 | L3 ≤ 初二水平；L5 ≤10 级；术语首现带括号解释；段落 ≤3 句；**禁文言文句式**（「此乃…之象也」） | NLP 工具自动检测 + 人工抽检 |
| 2.1-23 | 词库季度复审 | 季度三方复审（命理≥2+法务≥1+心理≥1）；更新率 ≥5%；报告存档 | 复审报告存在且同步 CI/CD |
| 2.1-24 | 词库回滚机制 | 更新后 7 天观察期；异常阈值触发一键回滚 ≤5 分钟；回滚后自动触发 A 类全量检查 | 回滚脚本/流程存在且有演练记录 |

## 三、计划口径要点结论

1. **「三级转译」不是一个功能，是一条带 24 道闸门的内容生产流水线**——红线定义的是词库数据结构（L1-L5 分层字段）、生产流程（审核/复审/签字）和运行时防护（熔断/兜底/脱敏）三层。
2. **数据结构核心是 archetype_key**：引擎输出与词库条目经 `{system}-{category}-{term}-{variant}` 键对接，词库按原型（非按词条）组织。
3. **MVP 范围已拍板**：800 条高频原型 × L4-L5 矩阵（CTO Phase3 + 白皮书 2.2 决策 3），非 5000 全量。
4. **运行时硬约束已拍板**：temperature=0（2.1-06/2.2-01 关联）、脱敏硬编码（2.1-08）、三元组版本化（2.1-09）。
