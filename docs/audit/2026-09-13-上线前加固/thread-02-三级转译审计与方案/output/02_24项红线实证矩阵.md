## 二、AI 调用链实测（src/lib/ai/proxy.ts）

- 定位：**纯透传代理**。前端用 packages/core/src/prompt/* 生成结构化盘面 prompt → POST /api/ai/analyze → proxy 加一句 system prompt（`请根据用户提供的排盘资料和问题直接解读`）→ OpenAI 兼容接口（默认 deepseek-chat）SSE 流式回传。
- 参数：`temperature: 0.7`（proxy.ts:140）、`max_tokens: 4096`、prompt ≤50K 字符、≤30 条消息。
- **有**的防护：SSRF 防护（自定义 baseUrl 禁内网/元数据地址）、请求体限长、上游重试/超时、错误消息用户友好化（无堆栈）。
- **无**的防护：禁用词表、输出脱敏、越界检测、语义熔断、模型版本锁定、报告版本元数据。

## 三、prompt 生成端实测（packages/core/src/prompt/*）

- 结构化盘面 + 25 主题（八字）/各体系 topic + 流派选择；guidance.ts 提供各体系「解读指引 + 参考书目」（书名级，如「参考《渊海子平》《三命通会》…」）。

## 五、特别核查项结论（任务卡指定）

1. **2.1-06 熔断器三要素**：Temperature=0 ❌（实测 0.7）；词库版本冻结 ❌（无 dict_version）；注入防护 🟡（有 SSRF/限长，无 prompt 注入防御——用户输入直接进 user message）。
