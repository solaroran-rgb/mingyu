## 一、任务背景

网站面向 7 语言（zh-CN/en/es/ja/ko/th/vi）。当前 i18n 只覆盖 UI 词条（134×7，76 条待母语复核），**排盘转译结果的 7 语言输出没有落地机制**。难点不是普通文件翻译，而是**古文化文言文的翻译**：术语（十神/星曜/神煞/卦名）、典故、语境、吉凶方向的保真。用户要求：排盘结果直接翻译、以及第一次（L1 古籍原文）/第二次（L3 白话）/第三次（L5 场景）转译结果分别做多语言翻译，都达到准确性 100%。

## 二、任务目标

1. **深度审计排查**：现有翻译链路全貌（UI i18n / prompt 语言参数 / 回译机制 / 术语表），指出断点。
2. **定义「100% 准确」的操作化口径**：区分「确定性字段（数值/干支/星曜位置/卦名/时辰）」与「语义字段（解读文案）」——确定性字段必须 100% 一致，语义字段定义分级验收标准（术语 100% 查表命中、数值 100% 不变、回译一致率 ≥98%、母语复核 0 硬伤），不承诺不可验证的绝对。
3. **执行计划**：7 语言术语表 → 翻译管线（术语查表 + 数值不变 + LLM 受限翻译）→ 回译校验 → 母语复核 → 上线门禁。

## 三、任务范围

- 翻译对象链路（四层）：
  - L0 排盘结果直接翻译（干支/星曜/宫位/卦象等结构化数据）
  - L1 古籍原文（第一次转译结果）
  - L3 通用白话（第二次转译结果）
  - L5 场景文案（第三次转译结果）
- 7 语言：en / es / ja / ko / th / vi（zh-CN 为源）。
- 术语域：十神、紫微星曜、神煞、卦名（六十四卦）、节气、五行、干支、流派、十二宫、大运/流年等（对齐 lexicon 1180 条）。

## 四、执行步骤

### S1 现有链路审计（1 天）
- 读 `src/i18n/locales/*.ts`（7 语言 UI 词条结构）；读 i18n 复核清单 `docs/i18n/2026-09-12-native-review-checklist.md`（76 条）。
- 查排盘→文案链路：`src/lib/public-api/`、prompt 生成器（`packages/core/src/prompt/*` 与前端调用处）是否有**语言参数**、是否有多语言输出分支、是否有回译校验——预期：无，需实证。
- 产出 `output\01_翻译链路审计.md`：链路图（文本）+ 断点清单（每条：位置/影响/证据）。

### S2 「100% 准确」操作化定义（0.5 天，与用户确认口径后定稿）
- 产出 `output\02_准确性口径定义.md`：
  - 确定性字段（数值、干支、星曜、卦象、时辰、节气）→ **100% 逐字段一致**（机器断言，自动化测试）；
  - 术语字段 → 100% 查表命中（7 语言术语表，术语不可意译/自由发挥）；
  - 语义字段（解读文案）→ 分级：忠实度 5 级评分（≥4.5 均分）+ 回译一致率 ≥98% + 母语复核 0 硬伤（吉凶方向反转/恐吓化/医疗法律越界为硬伤）；
  - 未达标字段必返回「未翻译/需人工」，**禁止静默降级**。

### S3 7 语言术语表建设（核心重活，2–3 天）
- 以 lexicon 1180 条为源，逐条给出 7 语言标准译法；字段：`{archetype_key, 中文术语, pinyin, 各语言译法, 出处/依据, 状态}`。
- 来源优先级：典籍英译惯例（如《紫微斗数全书》英译）、权威术语库、母语者确认；无权威译法的标「待定」不编造。
- 产出 `output\terms\7lang-terms.csv`（或 md）+ `output\03_术语表审计.md`（覆盖缺口：1180 条里多少条有可靠译法）。

### S4 翻译管线设计（1.5 天）
- 设计翻译架构：L0 结构化数据（干支等）→ **纯查表 + 数值直译**（确定性 100%）；L1/L3 文案 → 术语查表强制替换 + LLM 受限翻译（temperature=0、术语表注入、禁改数值/方向）；L5 场景文案 → 同上 + 场景模板校验。
- 明确管线位置：前端调用时传 `lang`，或后端 `prompt-builders` 加语言分支——给出推荐与理由。
- 产出 `output\04_翻译管线方案.md`：数据流图（文本）+ 每层实现方式 + 失败降级策略。

### S5 校验体系（1 天）
- **回译校验**：zh→X→zh 自动化脚本（复用 8877 LLM 或本地模型），对齐术语/数值/方向；产出 `output\05_校验脚本说明.md` + 脚本。
- **母语复核**：将 76 条 UI 清单 + 各层翻译抽样（每语言 ≥50 条）打包为复核表，交母语者；复核表格式含「原文/译文/问题/修改建议」。
- **上线门禁**：定义 CI 检查（确定性字段 100%、术语命中 100%、回译 ≥98%、无硬伤）→ 纳入 T4 回归。

### S6 报告收口（0.5 天）
- `output\审计报告_多语言翻译现状与执行方案.md`：现状结论 + 方案 + 工作量 + 依赖。

## 十一、风险与边界

- 「100% 准确」必须操作化：确定性字段可承诺 100%，语义字段以分级指标验收——**严禁宣称无法验证的绝对准确**（诚实第一）。
- 文言文多语言翻译的术语空缺是常态：缺权威译法的标「待定」，不做自由发挥。
- 本线程不做 UI 词条翻译本身（已在 i18n 清单），只做排盘内容链路的翻译。
