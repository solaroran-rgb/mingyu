# 05 · 校验脚本说明（T3·S5）

> 脚本：`output\05_backtranslate_check.py`（Python 3 标准库，零第三方依赖）
> 口径依据：`02_准确性口径定义.md` G3（回译一致率 ≥98%）与 G5（静默降级检测）
> 完成：2026-09-13 06:30

## 一、两种运行模式

```bash
# 1) 确定性完整性检查（不调 LLM，秒级，可进 CI 前置）
python 05_backtranslate_check.py --dry-run

# 2) 回译一致率试运行/实测（OpenAI 兼容端点）
set T3_LLM_BASE_URL=http://127.0.0.1:8080/v1      # 默认本地 Qwen3.8-27B
set T3_LLM_MODEL=Qwen3.8-27B-UD-VLM
set T3_LLM_API_KEY=...                             # 可选
python 05_backtranslate_check.py --langs en,ja,ko-KN,th-TH,vi-VN,es-ES --per-lang 6
```

## 二、检查内容

### dry-run（确定性，G2 前置）
1. tier1 行键格式（`^[a-z]+:[a-z0-9_]+:[a-z0-9_]+$`，T4 v1）；
2. `tier1_filled`/`tier1_supplement` 行 6 语言无空译文（空 → 硬伤）；`tier1_partial` 行的空译文计为「已知待定」（不进门禁断言集）；
3. 跨语言撞车预警：同一语言同一译文对应多个 zh。**当前 97 条全部为拼音罗马字结构性撞车**（丁/鼎→Ding、午/戊→Wu、乾/乾卦→Qian 等）——键（archetype_key）即消歧器（T4「键即契约」），渲染时上下文标签（柱位/宫位/卦名栏）天然区分，无需改译。

### LLM 回译（G3 主检）
- 分层抽样 tier1 术语（stem/branch/zodiac/wuxing/shishen/star/palace/gua/jieqi/shensha/jiazi/changsheng/bagua/liuqin/sihua/yinyang/term 配额制）；
- 每条：`{lang}译文 → LLM 回译 → 与 zh 比对`，判 `exact / near / miss / error`；temperature=0；
- 按语言输出一致率（exact+near 与 exact 分列）。

### extract_invariants()（供 CI 对整段文案断言）
`extract_invariants(text)` 提取文案中**必须跨语言保持**的不变量：全部数值、干支组合（六十字节 regex）；`invariants_preserved(src, tgt)` 断言数值逐字相等、干支不丢失。M4 中对 L1/L3/L5 译文逐句调用——数值或干支改变直接 FAIL（对应口径 C 类硬伤）。

## 四、验收边界（诚实声明）

- 任务卡验收「回译一致率 ≥98% 有实测数据」：**验收对象是 M1–M3 管线上线后的 L1/L3/L5 整段译文**（每语言 ≥200 句，含术语+文案混合样本），在 M4 入 CI 后持续出数。本次 36 条术语级试运行只证明机制可用、并已捕获 th 风险，**不得当作验收数据引用**。
- 门禁处置：G3 按语言分列，<98% 的语言该层文案整体降级 untranslated（口径第五节），不拖累其他语言上线。

## 五、CI 集成（M4）

```
pre-merge:
  1. build_terms_csv.py 重建 → 与 terms-7lang.ts 快照 diff（键变更须四线程会签）
  2. 05_backtranslate_check.py --dry-run（硬伤=0 才过）

nightly / release:
  4. G3: 05_backtranslate_check.py 全量（≥200 句/语言）→ 语言级一致率报告
```

失败处置一律按口径第五节降级，禁止跳过门禁发布。
