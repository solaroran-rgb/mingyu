## 六、缺口与风险

1. **tier2 846 条长尾**：地支关系 80、纳音 60、紫微格局 59、八字格局 57、紫微四化 51、二十八宿 28、二十四山 24、奇门 25、河洛 18、命理典籍 15、推命体系 14 等。建议二期顺序：紫微杂曜+四化+格局（L0/L3 高频）→ 纳音 → 神煞长尾 → 奇门六壬（出海 MVP 用量低，可最后）。
2. **键已对齐 T4 v1 三段格式**（2026-09-13 当日迁移完成，初版 PROPOSED-v1 已废弃）：实体名 slug 取 lexicon pinyin 去声调**连写**（词库 pinyin 无分词空格，如 `minggong`），与 T4 样例 `zheng_guan` 的分词风格有出入——四线程会签键表快照时统一（词库 pinyin 补分词，或快照按连写定稿）；稳定迁移键 = zh+category，脚本幂等可重跑。体系枚举（bazi/ziwei/yijing/liuyao/calendar/common/astrology/fengshui/qimen/liuren）为本表按 category 归类的提案，超出 T4 样例（bazi/ziwei/astrology）部分待会签。
3. **同词多域**（七杀、命宫、文昌等在 2 个 category 各有一行）：键不同、译法同——T2 定键时需裁定唯一键或域前缀规则。
4. **th 音译一致性**：拼音音译为机械规则，无领域权威 → 已全部标注待复核；母语者复核时优先统一音译方案。
5. **lexicon 结构限制**：LexiconEntry 无译名字段（BP6），本表为独立 CSV，后续若入代码库建议生成 TypeScript 常量（`src/data/terms-7lang.ts`），由 S4 管线消费。
