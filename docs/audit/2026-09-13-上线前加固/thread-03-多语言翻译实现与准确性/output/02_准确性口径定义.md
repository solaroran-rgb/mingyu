## 一、字段三分法（口径总纲）

| 类 | 字段范围 | 验收标准 | 验证方式 | 承诺 |
|---|---|---|---|---|
| **A 确定性字段** | L0 结构化数据：干支、星曜位置、宫位、卦名/爻位、时辰、节气、大运/流年干支、数值（分数/宫位数/日期时间） | **100% 逐字段一致**（7 语言渲染值 == 术语表查表值 == 引擎原始值） | 机器断言（CI 自动化） | 可承诺 100% |
| **B 术语字段** | 文案中出现的术语（十神/星曜/神煞/卦名/宫位/流派等） | **100% 查表命中**：术语必须来自 `7lang-terms.csv` 的 archetype_key，禁止模型自由发挥 | 机器断言（未命中即报错） | 可承诺 100% |
| **C 语义字段** | L1 古籍译文 / L3 白话解读 / L5 场景文案的整段文本 | 分级指标：忠实度 ≥4.5/5 + 回译一致率 ≥98% + 母语复核 0 硬伤 | 评分模型 + 回译脚本 + 母语者 | **不承诺绝对 100%**，以可验证指标替代 |

## 二、A 类：确定性字段 100% 的实现与断言

1. **前提**（依赖 BP1 修复）：排盘引擎输出结构含 `archetype_key`，中文仅为 value 之一；前端/管线按 locale 查 `7lang-terms.csv` 渲染。
2. **断言规则**：对每条黄金样例（与 T4 黄金样例库同源），逐字段断言：
   - 数值类：跨语言逐字节相等（日期/时辰索引/分数不得有任何转换损耗）；
   - 枚举类（干支/星曜/宫位/卦名）：`渲染值 == terms[archetype_key][locale]`，且 `terms[archetype_key].zh == 引擎原值`。
3. **失败处置**：任一字段断言失败 → CI 失败 → 禁止发布。**禁止静默降级为中文或英文兜底**；术语表缺行时渲染 `archetype_key` 原文并标记「未翻译」。

## 三、B 类：术语 100% 查表命中

1. 术语表：`output\terms\7lang-terms.csv`（字段：archetype_key / zh / pinyin / category / en / es / ja / ko / th / vi / basis / status）。
2. **规则**：译文文本中的术语必须以 `archetype_key` 为键注入或校验；LLM 翻译时术语表作为硬约束注入（temperature=0，禁改数值/干支/方向）；译后用表反向扫描，未命中的类术语词元 → 判 FAIL。
3. **术语表状态门槛**：仅 `status=tier1_filled`（或后续已复核状态）的行可进入断言集；`tier2_pending` 行参与渲染时输出「未翻译/需人工」占位。
4. 一键多域（如 七杀 同时属十神与紫微星曜）：MVP 单键复用，T2 对齐时可拆分域前缀。

## 四、C 类：语义字段分级验收

1. **忠实度 5 级评分**（评分模型 + 抽样人审，均分 ≥4.5 且 1–2 分占比 = 0）：
   - 5 完全等义（信息、语气、吉凶方向全一致）
   - 4 轻微语气/风格差，信息无损
   - 3 部分信息丢失或冗余（不影响结论）
   - 2 误导（语义偏移、程度失真）
   - 1 反向（吉凶颠倒、条件反转）
2. **回译一致率 ≥98%**：zh→X→zh 自动回译，对齐断言：术语逐词命中、数值/干支/方向零改变、语义等价（判定由评分模型给出 + 人工抽检 10%）。
3. **母语复核 0 硬伤**。硬伤定义（任一即 FAIL，不可均值豁免）：
   - 吉凶方向反转；恐吓化/夸大灾祸；
   - 医疗、法律、财务的越界断言（如「必患病」「必诉讼」）；
   - 数值/干支/星曜/卦名改变；典故张冠李戴。
4. L1 古籍译文额外门槛：典故逐条可溯源（译文旁注 archetype_key 或典籍锚点），无据可查的意译判 3 分以下。

## 五、门禁与 CI 集成（并入 T4 回归）

| 门禁 | 触发条件 | 处置 |

## 六、范围与边界

- 本口径适用于：L0/L1/L3/L5 四层 × 7 语言（en / es / ja / ko / th / vi，zh-CN 为源）。
- UI 静态词条（既有 i18n 136×7）沿用既有清单验收，其 76 条母语复核与本口径 C 类母语复核**共用同一复核渠道**（S5 复核表合并交付）。
- 「未翻译」占位是合法交付态；「翻译了但错」不是。
