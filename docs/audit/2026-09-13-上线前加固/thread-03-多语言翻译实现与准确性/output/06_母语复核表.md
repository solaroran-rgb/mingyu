## 使用说明（复核人必读）

1. **复核范围**：本表为 Part B（排盘术语译文）。Part A（UI 静态词条 76 条）
   直接使用既有清单：`docs/i18n/2026-09-12-native-review-checklist.md`（格式已备好，勿改结构）。
2. **硬伤定义**（来自《02_准确性口径定义.md》，任一即判 FAIL，逐条注明）：
   - 吉凶方向反转；恐吓化/夸大灾祸；
   - 医疗、法律、财务的越界断言；
   - 数值/干支/星曜/卦名改变；典故张冠李戴；
   - 术语错译（如西方占星词冒充东方术语：metaphysics/synastry 类错误）。
3. **填写方式**：每行在「问题」写现象（无问题留空），「修改建议」给出首选译法，
   「结论」三选一：`采用现译` / `建议改译` / `保留原文`。
4. **优先级**：先扫「结论=建议改译」，再补全空行；单语言预计 30–45 分钟。
5. 品牌名「命律 / TempoSoul」不译；拼音类译名（Jia/Ziwei 等）如所在语言有更通行惯例，请给建议。
