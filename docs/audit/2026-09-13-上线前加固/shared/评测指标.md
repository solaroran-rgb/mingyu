## 排盘准确性（T1）

| 指标 | 定义 | 目标 |
|---|---|---|
| 黄金样例一致率 | 逐字段判等通过数 / 黄金断言字段总数 | **100%**（用户要求排盘 100% 准确） |
| 权威站一致率 | 与 top5 权威站同数据比对一致样例数 / 样例数 | 100%（分歧须给出法理依据归类） |

## 通用规则

1. 一切指标须给出**可重跑脚本 + 原始数据落盘**（thread output 目录），禁止只报百分比。
2. 线上采样必须带浏览器头（CF 拦 python UA）且 ≥100 请求才谈比率。
3. 指标口径变更须四线程同步，本文件为唯一口径源。
