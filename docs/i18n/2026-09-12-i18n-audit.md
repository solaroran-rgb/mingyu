## 三、品牌一致性专项

- **zh-CN**：品牌字「命律」7 处（appName / loginTitle / registerTitle / premium.title / privacy.updatedAt / s1B1 / disclaimerBody）——正确。
- **en / es-ES / ko-KN / th-TH / vi-VN**：appName 均为 `TempoSoul`，复扫后 premium.title 均以 `TempoSoul` 开头，一致。
- **ja（人工复核项，未自动修）**：全文保留汉字品牌「命律」共 7 处：
  - `appName: '命律（テンポソウル）'`
  - `auth.loginTitle: '命律にログイン'`
  - `auth.registerTitle: '命律アカウントを作成'`
  - `premium.title: '命律プロ版'`
  - `privacy.updatedAt` / `privacy.s1B1` / `privacy.disclaimerBody`
  - 理由：日语可直读汉字，ja 端将「命律」作为正式品牌名使用是** deliberate 设计选择**，与其他 5 个拉丁字母 locale 统一 TempoSoul 的策略并不冲突。是否需要把 ja 也改成 TempoSoul，属于品牌决策，不在工程自动修复范围内，移交人工。

## 四、译文长度告警（316 条 warning）说明

阈值：`len(译文) / len(zh-CN) > 3`。

**性质判定**：中文为高密度表意文字，2 个汉字承载的 UI 词在 en/es-ES/vi-VN 等拉丁字母语言中自然膨胀到 6–14 字符（3–7×），在谚文/泰文中同样膨胀。这是跨语言翻译的语言学常数，**不是翻译质量问题**。316 条 warning 全部落在这一规律区间内。

**需要视觉走查的子集**（短 UI 标签，窄屏可能换行）：

- 导航/按钮/字段类（zh-CN ≤ 2 字，译文 ≥ 7 字符）：`nav.login`（es-ES 7×）、`nav.register`（es-ES/th-TH 5.5×）、`common.error`（en 6.67×）、`auth.email`（es-ES 9×）。
- 极端比值 Top（>6×，均为短词膨胀）：`auth.email` es-ES 9×、`nav.login` es-ES 7×、`auth.loginSubmit` es-ES 7×、`tutorial.step1Title` es-ES 5.83×。

处理决策：**不改译文**，移交前端在窄屏（360px）下对导航栏与表单字段做一次视觉走查即可。
